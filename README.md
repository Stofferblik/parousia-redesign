# Parousia Zoetermeer: ontwerpvoorstel nieuwe website

Statische conceptversie van een vernieuwde website voor Evangelische Gemeente Parousia Zoetermeer. Dit is **niet** de officiële website; die staat op [parousiazoetermeer.nl](https://www.parousiazoetermeer.nl).

- Pagina's: `index.html` (home), `zondag.html`, `meedoen.html`, `contact.html`
- Stijl: `css/tokens.css` en `css/bundle.css` komen uit het Parousia design system; `css/site.css` bevat paginazaken (conceptbanner, mobiel menu)
- Foto's en logo in `images/` zijn overgenomen van de huidige website
- Formulieren versturen niets; zoekmachines worden geweerd met `noindex`
